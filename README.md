# PRODIGY_DS_01

## Task 01 – Data Visualization using Bar Chart and Histogram

### 📌 Objective

The objective of this task is to create visualizations that represent the distribution of a categorical or continuous variable using a suitable dataset. This project demonstrates how to use Python libraries to analyze population data and present it through informative charts.

---

## 📂 Dataset

* **Dataset:** World Bank Population Dataset
* **Source:** https://data.worldbank.org/

---

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

---

## 📊 Data Visualization

The following visualizations were created:

1. Population Distribution Histogram (2024)
2. Top 10 Most Populated Countries Bar Chart

These visualizations provide insights into the global population distribution and highlight the countries with the highest populations.

---

## 📈 Key Insights

* The global population distribution is highly right-skewed, with most countries having relatively small populations.
* A few countries account for a significant portion of the world's population.
* India and China are the two most populous countries.
* The Top 10 Population Bar Chart provides a clear comparison of the world's most populated nations.
